# COVID-19 Case Analysis

**Project Overview**
This project analyzes the global impact of the COVID-19 pandemic using data analysis and visualization techniques. The goal is to explore patterns in infection rates, mortality trends, vaccination progress, and generate insights from historical COVID-19 data.

The project uses Python and Jupyter Notebook for exploratory data analysis (EDA), visualization, and trend analysis.

---

## Project Objectives

This analysis aims to answer the following questions:

- Which countries had the highest infection rates?
- Which countries recorded the highest death rates?
- What was the mortality rate trend over time?
- How did vaccination rates influence case declines?
- Can future outbreaks be predicted using historical trends?
